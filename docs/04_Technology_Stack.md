# Technology Stack: Numero Sansar

## Robust & Scalable Architecture
Numero Sansar is built on a modern, decoupled architecture that ensures high performance, security, and scalability.

### Frontend
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Performance**: Server-side rendering (SSR) and static site generation (SSG) for lightning-fast load times.
- **Responsive**: Mobile-first design principles.

### Backend
- **Framework**: CodeIgniter 4 (PHP 8.1+)
- **Architecture**: REST API
- **Authentication**: JWT (JSON Web Tokens) for secure, stateless user management.
- **Database**: MySQL with optimized indexing for historical data retrieval.

### Key Technical Advantages
*   **Security**: Encrypted data storage and secure API endpoints.
*   **Interoperability**: Decoupled frontend/backend allows for easy integration with future mobile apps or 3rd party services.
*   **Professional Output**: Robust engines for PDF (jsPDF) and Excel (XLSX) generation.
*   **Global Readiness**: Built-in foundation for multilingual support and regional configurations.
